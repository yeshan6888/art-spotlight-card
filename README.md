# Art Spotlight Card

A static, responsive gallery of six interactive relief cards. Each detail view reads its own `card-config.json`, original image, normal map, height map, and roughness map.

## GitHub Pages

This repository is configured to publish from the `main` branch root. Enable Pages in **Settings → Pages** and select **Deploy from a branch → main → /(root)**.

## Local preview (macOS)

Double-click `start-preview.command`. It starts a local HTTP server and opens the preview in a browser.
